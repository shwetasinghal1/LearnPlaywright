# LearnPlaywright

A learning repository for JavaScript fundamentals and Playwright-related practice. The project is organized into chapters covering basic syntax, JavaScript concepts, variables, literals, operators, switch statements, and conditional logic.

## Repository Structure

- `chapter_1_basics/` - Basic JavaScript usage examples
- `chapter_2_JavaScriptConcepts/` - JavaScript concept exercises
- `chapter_3_JavaScript_laterals/` - Examples of JavaScript literals
- `chapter_4_JavaScript_Variables/` - Variable declarations, scoping, and hoisting
- `chapter_5_Literals/` - Literal values and template strings
- `chapter_6_operators/` - Operator examples and practice programs
- `chapter_6_switch/` - Switch statement examples and day-checker logic
- `chapter_7_ifelse/` - If/else conditional logic practice

## How to Use

1. Open this repository in a code editor.
2. Review the chapter folders to explore examples and practice files.
3. Run JavaScript files using Node.js, if installed:

```bash
node <path-to-file>
```

## Notes

- This repository is designed for hands-on practice and learning.
